# Tenda F3 Router Analysis
This project explores hardware, firmware and security of the Tenda F3 Router for educational purposes.

As an electrical & electronics engineer who is interested in cybersecurity, I believe that one of the best ways to learn about electronics is getting your hands dirty and starting practical analysis of electronic devices. Taking a device apart and analyzing it can teach you as much as building it from scratch. So, this is a journey starting from hardware components to its running services.
